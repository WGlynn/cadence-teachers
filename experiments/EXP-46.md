## Summary
- Question: Cadence 0.83 adds an opt-in episodic memory (`Brain.compose(memory_choice=True)`). Upstream reports, on its own four-step crafting chain, frozen full-chain success 38.1% -> 98.7% with a caregiver, 9.0% -> 97.8% after 80 episodes alone through `live`, 9.1% -> 73.2% from reward alone. EXP-45 showed that on Stone Age V5's chamber full-chain success is mostly in-attempt search (a no-knowledge never-repeat searcher gets .304) and that the default brain learns the chain from no signal (per-state greedy accuracy .33-.42). Does the memory change that on this outside chamber, state by state?
- Setup: EXP-45's replica of V5's chamber (reproduces V5's published per-seed numbers). Brain = the current default composition, `Brain.compose(7, 5, modules=(48, 24), arousal=True)`, with and without `memory_choice=True` (its own defaults, nothing tuned). Signals: natural (world reward only), grade-v5 (V5's guided +-.5), corrective (V5's caregiver labels on executed mistakes). 120 teaching attempts, then 80 attempts alone through `live` with world reward only. Readings on frozen copies after teaching and after the 80 alone: per-state greedy accuracy (primary), greedy full-chain, sampled full-chain over 100 attempts. Seeds 42-53.
- RUN GATE: (1) prediction below, written before the pilot. (2) Window: a 3-seed pilot at the exact run conditions; a 1-seed 10-attempt smoke run was seen (code check only: memory/corrective all four states right, without memory .25). If the pilot puts every memory arm at the ceiling, the full run keeps the design (the claim under test is a ceiling claim) and the write-up says the budget cannot rank memory arms. (3) Variance: seeds vary; arms differ only in memory and signal. (4) Metric: per-state greedy accuracy is primary; full-chain is read against the never-repeat searcher (.304). (5) Chain: train success -> taught acc -> taught sampled -> alone train success -> after acc -> after sampled.

## Reflection
- What it means: the strongest outside confirmation of a Cadence release claim we have produced. Upstream's own table (38.1 -> 98.7 corrected, 9.1 -> 73.2 from reward alone, 9.0 -> 97.8 after the caregiver leaves) lands on a chamber upstream did not build, read by an instrument (per-state greedy accuracy) that search cannot pass: .193 -> .963, .092 -> .777, .276 -> .955 sampled, and per-state .58 -> .94, .29 -> .75. Before the memory, the default brain's best full-chain numbers were search; with it, they are a chain. One thing upstream's table does not show and this does: after the caregiver leaves, the corrected chain's stage answers drift through `live` too (all four right fell 9 -> 5 of 12) while full-chain success holds, because the carried context covers the drifted stage. Upstream's caveat names the stall through `step` and says `live` avoids it; here the per-state reading drifts through `live`, and the full-chain reading hides it.
- Process: pre-registered and pushed before the pilot; pilot read before the full run; no design change. The replica check hitting upstream's 0.82 figure exactly (.264) is what lets this read as a test of the release and not of our chamber. Limits: the memory arms sit near the ceiling at 120 attempts, so this cannot rank them or show learning speed; one chamber, episodic with done flags (upstream's no-done continuing chain and the history-free bandit loss are not tested); 12 seeds; reward-alone is bimodal (2 seeds at .25), so its mean .75 sits exactly on P2's threshold; P3's wording ("within .1") was loose for an arm that improved.
- Lesson: a release claim measured with full-chain success can be replicated or refuted only by an instrument search cannot pass; read per-state accuracy beside it, and the drift that full-chain success hides shows up.
- Next: learning speed at smaller budgets (10, 20, 40 attempts) where the memory arms are off the ceiling; the drift after the caregiver leaves (which stage, how fast, `live` vs `step`); the memory on our delayed-credit brain (EXP-45's winner) to see whether the two compose; and a note to upstream with these numbers (Will-gated).
